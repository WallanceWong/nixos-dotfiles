# Whisper

*A night sky over the city, lit by a streetlamp.*

The VS Code part of the **whisper** rice — the same palette as the desktop
(`theme/palette.json` in the dotfiles), generated, not hand-copied.

- **Colours** — deep blue-teal surfaces, text like moonlit paper, and the
  streetlamp's warm yellow for what matters: the caret, function names, the
  active tab. Keywords are the teal of the sky, strings the green of the
  bushes, numbers the warm light of windows; macros and registers are violet.
- **Tonight's moon** in the status bar, with its Japanese name and the date —
  `● 新月  十月十日`. Click it for the phase and the days to the full moon.
- **Whisper: Night mode** — `Ctrl+K Ctrl+N`. Fullscreen, centred, quiet.
- **OS-dev snippets** — C: `kmain` `portio` `serial` `gdt` `idt` `panic`
  `packed` · assembly: `multiboot` `isr` `lgdt` `portio` · linker: `kernel-ld`.

Built and installed by the dotfiles (`theme/vscode/module.nix`); edit there.
